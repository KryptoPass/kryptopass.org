# kryptopass.org

Source of the official KryptoPass website, built with [Astro](https://astro.build/).

> The site is a work in progress. For the app itself, see
> [KryptoPass](https://github.com/KryptoPass/KryptoPass).

## Run it locally

Requires Node.js and [pnpm](https://pnpm.io/).

```sh
pnpm install
pnpm dev       # local server at http://localhost:4321
pnpm build     # static site in ./dist/
pnpm preview   # serve the build locally
```
